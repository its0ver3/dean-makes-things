Building KDI - a karaoke difficulty checker

October 7, 2026

A friend had an idea for figuring out how difficult a karaoke song is to sing. It sounded like a fun little project, and an excuse to try Kimi K3 and DeepSeek V4. I hadn’t used either before, so I bought some API credits on OpenRouter and took them for a spin.

K3’s first implementation was pretty good. It did what I wanted and added some nice touches with the album art that surprised me. DeepSeek did a similarly good job, but I ran through the credits pretty quickly.

I was still having fun, so I switched back to Claude and kept working on the UI. Music is a big passion of mine, and there’s something really enjoyable about designing an app around your own hobbies. You get to make it look exactly how you want and add little details that most products wouldn’t bother with.

Spotify is a good example. It works, but it isn’t laid out the way I’d want to browse and listen to my music. I imagine a lot of that comes from their goals around pushing playlists and other content. This project made me want to build my own music player so I could have more control over my library and how I use it.

I only spent a couple of hours on this, but I learned a good amount. I’ll still be sticking with my OpenAI and Claude subscriptions for now. Even with relatively cheap models, I get so much more use out of those subscriptions than I did from the API credits.
